# TallyBack

*One place to store your bills for the future.*

Snap any bill or receipt, see the line that doesn't add up, and send one message on WhatsApp.
Every number is computed by code; the AI only reads the bill and writes the words.

Built for the 100xEngineers Cohort 8, Module 2 hackathon, problem 1: **BillShield**.
